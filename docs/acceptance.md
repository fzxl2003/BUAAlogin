# 实机与能耗验收

原生编译成功不等于已经证明降低能耗。没有校园网、真实凭据、Windows/Linux 实机和测量数据时，以下验收必须标记为待测，不能填写推测结果。正式替换前执行本清单。

## 自动验证

- 原生测试覆盖固定加密向量（含中文／emoji）、JSONP、完整登录与在线快速路径、门户 IP 与本地 IP 不同的路由器 NAT、challenge IP、强制登录获取新 IP/ac_id、注销、认证限制分类、三轮外网失败、同出口周期去重、恢复升级、跳转限制、取消、统一周期、运行中修改周期、通知去抖、睡眠恢复、凭据缺失及 CLI SIGTERM。
- `cargo test --locked -p buaa-core --features browser-fallback` 在装有兼容浏览器时运行本地门户的真实 DOM 输入、注销/登录可信点击、确认弹窗、控件歧义、验证码识别及 profile 清理测试。没有兼容浏览器时该实测用例明确输出 SKIP；其通过不能替代校园网实测。
- 按当前要求，发行 CI 只执行 Windows/macOS 原生构建打包和 Linux amd64/arm64 镜像构建，不运行测试、格式／lint 门禁或容器 smoke test。上述测试代码保留，但不会自动执行；成功的发行工作流只证明构建和发布完成。

## 实机功能

在 Windows 10/11 x64、macOS 12+ ARM、Linux amd64/arm64 分别记录系统、版本、构建 SHA、结果与日志。

1. 无 Python 环境解压启动；桌面版无需管理员权限，窗口、托盘、隐藏、显示、停止与退出正常。
2. 从账号弹窗输入并保存账号密码；检测并多选校园网接口，分别设置自定义网关，再通过连接页认证测试验证首次登录、已有认证状态、静默踢下线与自动重连。
3. 验证电脑通过路由器 NAT 接入校园网，登录参数使用门户识别的校园网 IP。另同时启用校园 Wi-Fi、USB 上联、VPN 与系统代理，确认认证请求仍从正确接口到网关，不泄露至其他上联。
4. 切换 IPv4、拔插网线、断开／重新连接 Wi-Fi；指定接口消失时等待该接口；通知风暴不产生重复认证。
5. 睡眠期间无认证请求，恢复仅合并检查一次；请求中停止／退出可取消传输，空闲中停止立即返回。
6. 记住凭据、重启读取、取消记住后删除；旧版凭据不被读取或删除。
7. Docker 空数据卷启动时输出一次性设置码，设置管理密码后可登录；旧 `USERNAME`/`PASSWORD`/`INTERFACE` 仅首次导入，完整账号自动监控。显式接口透传，多接口中一个失败不阻止其他接口在线；`docker stop` 正常退出，非 root 用户可写 `/data` 且无需 NET_ADMIN/NET_RAW。
8. 接口列表明确标注 Wi-Fi／有线；Wi-Fi 网卡在无 IP、未检测到校园网时仍然列出并可配置 `BUAA-WiFi`、`BUAA-WiFi-Free` 和自定义 SSID，有线接口详情不出现 Wi-Fi 选项。验证系统扫描结果触发连接、停止／睡眠暂停、权限不足提示和配置持久保存。
9. TLS 证书错误、HTTP/跨域跳转、异常 JSONP、错误密码及网关不可达，确认失败且日志无原始凭据／token。
10. 网关在线但两个外网站点均失败：确认三轮复核、协议注销重登、网页兜底按顺序且各最多一次；单站失败或瞬时故障不注销。失败后按配置周期继续检测，网络通知和同 NAT 的另一接口不使同周期内重复恢复。
11. 在真实门户采集脱敏 DOM，确认登录/注销选择器、确认框与所需资源都可经网关域名加载；只有实测确认后才能扩展代理域名白名单。当前这项及真实多网卡/VPN、睡眠恢复后的浏览器行为均为待测。
12. 在网页恢复中停止、睡眠、切换接口、退出，确认无后续点击/认证请求、无浏览器或代理进程遗留；卸载/移动浏览器、页面改版、验证码、密码错误时明确说明原因。正常在线时无浏览器进程。
13. 分别开关认证、外网检测和网页兜底，确认外网关闭时网页开关联动关闭；三种测试不可重入，结果与下次运行时间独立更新。
14. macOS 与 Windows 均可在“设置”页修改检查周期；验证低于 10 秒、非整数、保存与重新启动读取，运行中修改后各启用任务的下一次时间同步更新，连续失败不退避、没有额外恢复冷却。
15. 确认开始／停止共用一个按钮，连接页标题区不显示认证／外网绿点；“设置”页包含最近活动、开机自启和浏览器路径，日志按日写入、脱敏、清理 30 天前文件，且按钮能打开 Finder／Explorer 日志目录。
16. `rad_user_info` 返回 `sum_bytes` 后，连接页显示已用流量；设置总流量后进度条比例正确，缺少或异常流量字段时显示未知且不影响连接。

## Docker 网页端验收

1. 在 Linux amd64 与 arm64 构建镜像，确认运行时只包含 `buaalogin-web`，健康检查通过，页面不加载外部资源，镜像不包含 Chromium/Node.js。
2. 分别用桌面和手机浏览器检查“连接 / 设置”布局、浅色/深色模式、窄屏换行、流量进度和无多余页面底部空白；视觉间距、卡片和操作层级与 macOS 版一致。
3. 验证首次设置、登录失败限流、24 小时会话、退出、修改管理密码、Origin/CSRF 拒绝和 SSE 断线重连。除登录/会话初始化所需的 CSRF 值外，API 和下载日志不得出现校园网密码、设置码、session cookie 或校园网认证 token。
4. 运行期间确认账号、接口和任务开关被锁定，检查周期实时更新、总流量可随时修改；认证测试和外网测试串行执行且不可重入。
5. 检测接口后确认 Wi‑Fi/有线标注；未检测到校园网的 Wi‑Fi 仍保留。空选择按自动模式运行，显式多选时逐接口使用自定义网关。页面不提供宿主 Wi‑Fi 连接控件。
6. 显式开始、停止、正常重启、SIGTERM 和异常 core 停止各执行一次；确认期望运行状态正确持久化，异常停止保留期望状态并在 30 秒后重试。
7. 在只读/损坏数据、错误目录属主、无凭据、旧配置迁移和已有网页配置加环境变量的组合下启动，确认错误明确、已有配置不被覆盖、文件权限为 0600、日志超过 30 天会清理。
8. 从另一台局域网设备访问并确认页面醒目标注 HTTP 风险；经 HTTPS 反向代理访问时保留 Host，写操作 Origin 校验正常。不得直接将 HTTP 端口暴露至公网。

## 能耗实验

固定同一设备、系统电源模式、屏幕状态、Wi-Fi、其他后台负载和检查间隔。依次对旧版及原生版各进行 **至少三次 30 分钟稳定在线测试**，交替运行顺序，每次只运行一个版本；另测断网等待、接口切换及重复失败。保留原始数据，采集器本身的开销须一致。

| 场景 | 版本 | 时长 | CPU 时间 | 常驻内存 | 唤醒次数 | 子进程创建 | 认证请求数 | 能耗/测量方法 |
|---|---|---|---|---|---|---|---|---|
| 稳定在线 1/2/3 | 旧版／原生 | 各 30 分钟 | 待测 | 待测 | 待测 | 待测 | 待测 | 待测 |
| 无接口等待 | 旧版／原生 | 相同时长 | 待测 | 待测 | 待测 | 待测 | 待测 | 待测 |
| 接口切换／失败 | 旧版／原生 | 相同操作 | 待测 | 待测 | 待测 | 待测 | 待测 | 待测 |

macOS 用 Instruments 的 System Trace／Energy Log（视本机可用模板）记录 CPU、唤醒与进程创建，配合活动监视器及受控抓包统计请求；Windows 用 WPR/WPA 对比 CPU、进程生命周期、网络与可用电源指标；Linux 用 pidstat、perf／支持硬件上的功耗计数及容器统计。没有可归属到进程的功率指标时明确标记缺失，不将 RSS 下降当作实际节能百分比。

通过条件：稳定在线无子进程、重复接口扫描或 UI 周期刷新；每个健康接口每 300 秒最多一次认证状态请求和两个并发外网 HEAD 请求（手动／网络事件触发单独统计）；无接口时无认证请求；睡眠、掉线、多接口、分级恢复和停止行为正确。浏览器只在网页恢复期间运行，完成即清理。CPU、唤醒与实际能耗相对基线降低；接近测量噪声则延长实验，不能宣称已证明节能。

通过后保存结果与构建 SHA，再手动运行 release workflow 的 promote_native。若出现认证或能耗回归，恢复此前发行版和对应镜像 SHA。
